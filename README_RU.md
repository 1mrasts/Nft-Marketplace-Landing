## NFT-Marketplace

Этот репозиторий — реализация сайта NFT-Marketplace на основе открытого макета.  
Макет сам по себе был чисто визуальным, без какой-либо логики, поэтому весь функционал написан с нуля.

## Стек технологий

### React + Vite + React-Router

- **React** — основа проекта. Вся логика и UI построены на React с упором на чистую архитектуру и читаемый код (никакого спагетти-кода).
- **Vite** — для быстрой сборки и суперскоростной разработки.
- **React-Router** — маршрутизация страниц и управление навигацией.

## Что умеет сайт

### Добавление NFT

- Можно добавить свой NFT прямо на сайте.
- Данные сохраняются между сессиями (кроме загружаемых изображений) через `localStorage`.
- NFT добавляется без регистрации, владелец присваивается автоматически (заранее подготовленный).

### Особенности и фишки

- Ручная прокрутка NFT на главной странице.
- Проект полностью построен по методологии FSD — легко поддерживать и расширять другим разработчикам.
- Мелкие интерактивные моменты для лучшего UX.

---

Проект задумывался как учебно-практический, с упором на чистую архитектуру и реализацию функционала с нуля.
