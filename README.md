## NFT-Marketplace

This repository contains an NFT-Marketplace website built from a publicly available design mockup.  
The mockup was purely visual with no functionality, so all features were implemented from scratch.

## Tech Stack

### React + Vite + React-Router

- **React** — the core of the project. All logic and UI are built with React, focusing on clean architecture and readable code (no spaghetti).
- **Vite** — for fast builds and lightning-fast development.
- **React-Router** — handles page routing and navigation.

## Features

### Adding Your Own NFT

- Users can add their own NFT directly on the site.
- Data persists across sessions (except uploaded images) using `localStorage`.
- NFTs can be added without an account; the owner is assigned automatically.

### Highlights & Extras

- Manual NFT scrolling on the main page.
- Fully structured according to FSD methodology — easy for other developers to continue and maintain.
- Small interactive touches for a better UX.
